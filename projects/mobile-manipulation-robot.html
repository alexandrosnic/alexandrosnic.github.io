Mobile Manipulation Robot

SLAM, navigation, planning and decision making for a TIAGo robot (KTH)

Description

Built during the Introduction to Robotics course at KTH Royal Institute of Technology. A TIAGo mobile manipulator, with onboard sensors and an arm, works in a simulated Gazebo environment and has to navigate between locations and carry out simple manipulation tasks.

My task was to implement the mission planner that sequences the robot's skills (localization, navigation and manipulation) so that TIAGo completes a set of tasks on its own.

Technologies Used

  • ROS
  • Gazebo / RViz
  • PAL Robotics TIAGo
  • SLAM and navigation
  • Mission planning and decision making
