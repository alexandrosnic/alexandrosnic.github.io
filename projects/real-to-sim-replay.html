Real-to-sim: replaying recorded human tasks on a robot arm

Checking, grasp by grasp, whether a robot could do what the worker did

Description

Egocentric recordings of people at work are valuable training data for robots only if a robot could actually reproduce what the person did. This pipeline answers that question per grasp, in simulation, before any hardware is involved.

Visual SLAM on the head-mounted camera recovers the room and where the worker stood, and hand tracking turns each grasp into a grasp pose and a release pose. A Franka Panda is placed at the worker's stance, inside a model of the recorded room, and replays every grasp the way a real arm is run: MoveIt 2 plans each leg (Cartesian paths for straight moves, OMPL for the carry) and ros2_control executes it on a MuJoCo scene.

Capabilities Demonstrated

  • Real-to-sim from egocentric data: room geometry, stances and grasp poses all come from the recording, with no manual scene building.
  • Production-style control stack: the same ROS 2 / MoveIt 2 / ros2_control path a physical arm would use, driving the simulator over a hardware interface.
  • Strict, explainable verdict: a grasp is usable only if every pose is reached within 2 cm and 10°, nothing collides with the room and the box is not dropped; otherwise the first failure is named (unreachable, collision, path blocked, dropped).
  • Measured result: 32 of 44 recorded grasps usable; the same task also runs on a UR5e and a WidowX arm.

Technologies Used

  • MuJoCo
  • ROS 2, MoveIt 2 (OMPL), ros2_control
  • Visual SLAM on egocentric video
  • Docker
